# SoberSpend Backend

A Nuxt 4 backend with AI-powered receipt analysis using Ollama and Supabase for data persistence.

## Features

- 🤖 AI-powered receipt analysis with personalized financial roasts
- 📊 User onboarding with bad spending habits tracking
- 💾 Supabase integration for data persistence
- 🔒 TypeScript with full type safety
- ✅ Zod validation for runtime type checking
- 🧪 Comprehensive test suite with Vitest

## API Endpoints

- **GET /api/** - Health check with database verification
- **POST /api/onboarding** - User onboarding with bad habits prompt
- **POST /api/analyze-receipt** - AI-powered receipt analysis

## Setup

### 1. Install Dependencies

```bash
pnpm install
```

### 2. Configure Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Edit `.env` with your credentials:

```env
# Supabase Configuration (Required)
SUPABASE_URL=your_supabase_url_here
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key_here

# Ollama Cloud Service (Recommended)
OLLAMA_BASE_URL=https://ollama.com/api
OLLAMA_MODEL=llava
OLLAMA_API_KEY=your_ollama_api_key_here
```

#### Getting Ollama API Key

1. Sign up at [ollama.com](https://ollama.com)
2. Go to [API Keys Settings](https://ollama.com/settings/keys)
3. Create a new API key
4. Copy the key to your `.env` file

#### Alternative: Local Ollama

If you prefer to run Ollama locally:

```env
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llava
# OLLAMA_API_KEY not needed for local
```

Install Ollama locally: [ollama.com/download](https://ollama.com/download)

### 3. Set Up Supabase Database

Run the schema from `old.backend/supabase_schema.sql` in your Supabase SQL Editor:

```sql
create table if not exists public."Users" (
    id text primary key,
    bad_habits_prompt text not null
);

create table if not exists public."Transactions" (
    id bigint generated by default as identity primary key,
    user_id text not null references public."Users"(id) on delete cascade,
    amount integer not null,
    category text not null,
    timestamp timestamptz not null default now()
);

create index if not exists transactions_user_id_idx on public."Transactions"(user_id);
create index if not exists transactions_timestamp_idx on public."Transactions"(timestamp desc);
```

## Tech Stack

- **Framework**: Nuxt 4 with TypeScript
- **AI Integration**: AI SDK with ollama-ai-provider-v2
- **Database**: Supabase (PostgreSQL)
- **Validation**: Zod for runtime type checking
- **Testing**: Vitest with fast-check for property-based testing

## Migration from Python Backend

This is a complete rewrite of the original Python FastAPI backend in Nuxt 4. All functionality has been maintained while modernizing the stack:

- ✅ All API endpoints preserved
- ✅ Same request/response contracts
- ✅ Improved type safety with TypeScript
- ✅ Better AI integration with AI SDK
- ✅ Enhanced error handling and validation
